# Abstract Experience

SPA vanilla para una sala de juegos. No necesita dependencias ni proceso de compilacion.

## Estructura

- `index.html`: shell principal y punto de entrada.
- `app.js`: router sencillo basado en hash.
- `views/`: una carpeta por vista de la SPA.
- `games/`: un proyecto independiente por juego.

## Ejecutar

Abre la carpeta con un servidor estatico, por ejemplo:

```bash
npx serve .
```

Tambien puedes usar la extension Live Server de VS Code.
